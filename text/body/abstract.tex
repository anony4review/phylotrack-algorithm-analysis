\begin{abstract}

Agent-based models of eco-evolutionary processes are a powerful tool for computational biology.
Among other things, they are a powerful tool for producing ground truth data for testing phylogeny reconstruction techniques.
Because they directly instantiate the conditions that lead to evolution, they allow testing the impact of scenarios that would be impossible with backwards-time models.
The ability of these models to produce ground truth data comes from the fact that they enable perfect tracking of the actual realized phylogeny of the digital population.
However, tracking these phylogenies can impose a substantial time and memory cost on the program, limiting the conditions in which doing so is practical.
To ameliorate this problem, we describe a phylogeny tracking algorithm that improves on the current state of the art by counting references rather than performing the equivalent of garbage collection.
Whereas the current state of the art algorithm exhibits a tuneable trade-off between time and memory use, our algorithm enables efficiency in both simultaneously. 
Here, we present a formal analysis of this algorithm, including its time and space complexity.
Additionally, we provide a library in C++ and Python that implements our algorithm and present benchmarking results showing that it outperforms the current state of the art.

% In silico agent-based model systems for studying evolution instantiate the processes of heredity, variation, and differential reproductive success (\textit{i.e.} the three ingredients for evolution by natural selection) in digital populations. Consequently, these populations undergo evolution, and can be used as virtual model systems for studying evolutionary dynamics. This experimental paradigm -- used across biological modeling, artificial life, and evolutionary computation -- complements research done using in vitro and in vivo systems by enabling experiments that would be impossible in the lab or field. One key benefit is complete, exact observability. For example, it is possible to perfectly record all parent-child relationships across simulation history, yielding complete phylogenies (ancestry trees). This information reveals when traits were gained or lost, and also facilitates inference of underlying evolutionary dynamics.
% The Phylotrack project provides libraries for tracking and analyzing phylogenies in in silico evolution. The project is composed of 1) Phylotracklib: a header-only C++ library, developed under the umbrella of the Empirical project, and 2) Phylotrackpy: a Python wrapper around Phylotracklib, created with Pybind11. Both components supply a public-facing API to attach phylogenetic tracking to digital evolution systems, as well as a stand-alone interface for measuring a variety of popular phylogenetic topology metrics. Underlying design and C++ implementation prioritizes efficiency, allowing for fast generational turnover for agent populations numbering in the tens of thousands. Several explicit features (e.g., phylogeny pruning and abstraction, etc.) are provided for reducing the memory footprint of phylogenetic information.
